## Higgsfield Cinema Studio / Canvas Controls (Direct from Sources)
- **Aspect Ratio / Resolution**: Profile settings for default resolution and aspect ratio preferences. Native 21:9 CinemaScope for widescreen cinematic. Supports vertical (e.g. 9:16 for Reels/TikTok/Shorts), custom. "Using a vertical aspect ratio and subtle camera movement ensures the video feels premium while remaining platform-friendly." Grid/storyboard for multi-aspect planning.
- **Camera Style / Presets**: 50+ specific cinematic camera presets (static, handheld, push, pan, dolly, orbit, drone, crane, eyes-in/mouth-in extreme close-ups, etc.). "Camera movement follows the same philosophy. Instead of animating complex paths, you select intent." Trained on real cinematography for physics/momentum. Lens type, focal length, aperture, camera body simulation for optics (bokeh, depth, distortion, "mix 16mm grit with Anamorphic sharpness"). Panels for camera + manual custom style text fields.
- **Motion Intensity / Energy**: Genre selection (Action, Horror, Comedy, Suspense, Music Video, Commercial, etc.) "influences pacing, motion energy, and camera behavior." "Genre selection shapes pacing, motion energy, and overall visual tone." High-energy for action, subtle for premium/minimalist.
- **Mood / Tone / Pace**: Genre + style/lighting/color/temperature/contrast presets + manual custom fields. "Fine-tune color, temperature, contrast, and presets to get the exact tone you want." "Mood" in scene desc (time of day, atmosphere). Pace via genre + "slow build" vs fast in prompting or presets. "Hero Frame First": perfect still (lighting, mood, lens character, composition) then extend to motion for locked tone.
- **Brand / Reference Consistency Strength**: Elements (characters, locations, props) as reusable @tagged assets. "Create them once, reference them across shots with @tags... Elements stay consistent across every generation." Image-to-Video with "anchor" reference image for consistency. Start & End Frame for motion/continuity lock. Multi-reference, hero frame locking. Strength via "how strongly to adhere" in advanced prompts or weight (implicit in Canvas nodes). "lock in the lighting, mood, and lens character, then extend that exact frame into motion."
- **Music Sync / Beat-Matching**: Music Video genre supported. "joint audio-video generation" with Seedance 2.0 integration, synchronized sound and visuals, lip-sync. "unified audio-video". Prompt for "beat matched" or provide audio ref. In workflow: describe action synced to music.
- **Text Animation Style**: Not heavily explicit in public (focus on visual/cinematic), but "on-screen text", kinetic/lower thirds in marketing presets. Manual style input for custom text treatments. In Canvas: text as nodes editable.
- **End Card / CTA Style**: Marketing Studio presets include strong CTAs, end slates, logos (from Elements/brand refs). Custom via prompt or post (color grade, overlays). "end card" handling in community workflows.
- **Other Advanced**: "Hero Frame First" philosophy (perfect still before video for consistency). Unified Text-to-Image → I2V flow. 3D/Gaussian, VFX, inpaint, grid for storyboards. Real-time collab on Canvas. AI Director (Mr. Higgs) auto-breaks scenes, adjusts camera/style from natural lang + project Elements.

## Competitor Equivalents (Runway, Kling, Veo, Seedance, Luma, ComfyUI)
- **Aspect**: Most support via --ar or width/height params in API/prompt (Runway, Kling, Veo strong). ComfyUI: latent size nodes, aspect ratio nodes in workflows, easy for any (16:9, 9:16, 1:1, 4:5, custom). Vertical common for social.
- **Camera Style**: Runway has Director Mode, Motion Brush (paint specific motion), camera controls. Kling has Motion Control / specific moves. Veo/Seedance understand "dolly", "orbit", "handheld" in prompts. ComfyUI: ControlNet for camera paths, AnimateDiff with motion modules, GLIGEN for positioned motion.
- **Motion Intensity**: Genre/prompt ( "high energy action" vs "subtle slow push"). Seedance/Kling excel at intensity without artifacts. ComfyUI: motion module strength, CFG, scheduling.
- **Mood/Tone/Pace**: Strong in all via prompt + style refs + lighting desc. "warm cinematic", "futuristic neon", "minimalist clean". Pace via timing in storyboard or "fast cuts" vs "slow lingering". Runway/Studio strong for tone lock via refs.
- **Reference / Brand Consistency Strength**: All top models improved with multi-ref, IP-Adapter-like (ComfyUI native strong), first/last frame, character lock. "strength" often via weight param (0.6-1.0) or "exact match" language. Runway/Seedance praised for brand/product lock across clips. ComfyUI IPAdapter + regional conditioning for precise strength per area.
- **Music Sync / Beat-Matching**: Seedance/Kling/Veo have native audio+video or lip-sync. Prompt "animations perfectly synced to the beat of [describe music]". External: analyze audio for beats (FFmpeg or JS) then time prompts/keyframes. ComfyUI: can condition on audio features in advanced workflows, or post-sync.
- **Text Animation**: Prompt "kinetic typography with [style: bold reveal / letter pop / glitch fade]". Ideogram/Flux good for text keys. Post-burn with FFmpeg drawtext timed. ComfyUI: text nodes + animation scheduling.
- **End Card / CTA**: Prompt "professional end card with logo + CTA button [style]" + ref image. Post overlay. Marketing tools have templates for strong CTAs.
- **Lengths**: Many 5-15s native, extend/stitch for longer. Prompt "exactly 5 second clip". ComfyUI: frame count control in AnimateDiff/SVD nodes for precise 5s/10s at 30/60fps.
- **ComfyUI for Local "Higgsfield-like"**: Full node graph for all controls (aspect in latent, camera via ControlNet openpose/depth, motion via AnimateDiff + IPAdapter ref strength, mood via style LoRA/model, text via nodes, audio sync via extensions, custom short durations). Batch + precise for brand consistency.
